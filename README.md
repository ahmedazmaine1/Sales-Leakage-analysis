# Sales Performance & Revenue Leakage Analysis

An end-to-end analytics project: track monthly revenue, spot regional drops, and put a dollar figure on
where the business is losing money. It ends with a prioritised list of things to fix.

**Stack:** SQL (SQLite: joins, CTEs, window functions) · Python (pandas) · Excel (openpyxl, live formulas and charts) ·
an interactive HTML dashboard (Chart.js) · a Power BI build guide with DAX.

> The data is **synthetic** and generated by `generate_data.py` for a fictional retailer, *Northwind Outfitters*.
> It has realistic seasonality and growth, plus six planted business problems that the analysis has to find on its own.

## Headline results (FY2024–FY2025)

| Metric | Value |
|---|---|
| FY2025 net revenue | **$27.6M** (+6.4% YoY) |
| Revenue leakage, 24 months | **$7.5M** (13.9% of net revenue) |
| Realistically recoverable | **$2.2M** |

### Where the money leaks

| Leak | 24-mo amount | Recovery assumption | Recoverable | Fix |
|---|---:|---:|---:|---|
| Uncollected B2B receivables (>90 days) | $1.68M | 40% | $673K | Collections agency, credit holds |
| High-intent abandoned carts | $4.30M | 15% | $645K | Cart-reminder flow, fix the mobile shipping step |
| Excess returns (above baseline) | $1.07M | 50% | $533K | Size guide / fit tool for Footwear |
| Rep discounts above the 15% cap | $364K | 80% | $292K | Manager approval above 15% |
| Expired promo codes still honoured | $61K | 100% | $61K | Validate code dates at checkout |

### Key findings
1. **West region H2-2025 revenue is down 26.5% YoY**, while the other regions grew 9.3%. That is ~$950K below the peer trend, and almost all of it is in the Sales Rep channel (-30.6%).
2. **Root cause:** rep *W-Rep1* has logged no orders since May 2025, and their accounts were never fully reassigned.
3. **Two reps (W-Rep2, S-Rep1) account for 72% of above-cap discounting.** 79% of their orders break the 15% policy.
4. **994 orders redeemed expired promo codes**, so checkout is not checking expiry dates.
5. **$1.68M of invoices are more than 90 days overdue.** South holds a third of it.
6. **Mobile users abandoning at the Shipping step make up 44%** of high-intent cart losses ($1.9M).
7. **Footwear return rate is 9.7%** against a 2.5% baseline, and 59% of those returns cite "Wrong size".

## Project structure

```
generate_data.py           # builds 9 related tables (~280K rows) into data/
sql/analysis_queries.sql   # 11 named SQL queries (the analytical core)
run_analysis.py            # SQLite load → SQL → pandas sizing → Excel → dashboard

dashboard/index.html       # built interactive dashboard (light/dark, tooltips)

  sales.db                         # SQLite warehouse

  Revenue_Leakage_Report.xlsx      # 12-sheet Excel report
```

## SQL techniques demonstrated

| Query | Techniques |
|---|---|
| `monthly_revenue` | CTEs, LEFT JOIN of two aggregates, `LAG()` for MoM and YoY growth |
| `regional_monthly` | `LAG() OVER (PARTITION BY region …)` with a named `WINDOW` |
| `regional_drop_detection` | Conditional aggregation by period, correlated subquery for the peer benchmark, rule-based flag |
| `region_channel_drop` | Drill-down to find which channel drives a regional drop |
| `rep_performance` | LEFT JOIN dimension → fact, policy-breach counting, `MAX(date)` to spot inactive reps |
| `leak_expired_promo` | JOIN to a reference table to validate business rules |
| `leak_uncollected` | Date arithmetic (`julianday`), AR aging buckets |
| `leak_returns`, `category_margin` | 3-table joins, baseline comparison, below-cost detection |

## Methodology notes
- **Leakage** means revenue that was earned or nearly earned but not kept. It is measured as:
  discount above the 15% cap · discounts from codes used outside their valid dates · receivables more than 90 days past due ·
  unrecovered carts abandoned at Shipping/Payment (early-stage carts count as browsing and are excluded) ·
  refunds above the median category return rate, plus the cost of stock that could not be restocked.
- **Recovery rates** are planning assumptions, not facts. They are editable in the Excel *Leakage Summary* sheet, which recalculates automatically.
- The **regional drop** is reported as a revenue gap against peer growth. It is kept separate from leakage so nothing is double-counted.
